How to use this tool

  1. Choose a time window and minimum magnitude.
  2. Select a map marker or a Select button to load weather for that location.
  3. Switch °F/°C or local/UTC times. Open USGS to verify a report.
Understanding the data

Magnitude describes earthquake size, not shaking at your address. Depth measures distance below the surface. An epicenter is the surface point above the earthquake. Retrieved means when this page downloaded data; Occurred is the event time.

If data does not load

Use Refresh, check your connection, or try a private browser window. Browser extensions and source limits can block requests. Missing data does not imply safe conditions.
