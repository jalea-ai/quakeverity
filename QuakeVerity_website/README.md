# QuakeVerity
Independent educational earthquake dashboard by Jalea. AI-assisted initial implementation.

Publish index.html using GitHub Pages from main / (root).
Data: USGS GeoJSON summary feeds. https://earthquake.usgs.gov/earthquakes/feed/v1.0/geojson.php

Features: live retrieval on page load, filters, metrics, official event links, missing-value handling, UTC timestamps, error messages, descriptive code-generated brief.
Refresh occurs every five minutes only while the page is open. Table capped at 200 matches; metrics count all matching retrieved records. Not a prediction or emergency service. AI/Hermes integration is not implemented.

Before sharing: test deployment, data retrieval, filters, links, mobile layout, and offline error handling. Generated files have not been live-browser tested. Name has not undergone trademark clearance.
